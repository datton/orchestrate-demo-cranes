# The Story of Cranes

A text-only website on how cranes evolved in construction and the main technology changes along the way.
Static HTML, CSS and JavaScript. No build step, no images, no video.

## Pages
- `index.html`: Home
- `pages/ancient.html`: Ancient and medieval cranes
- `pages/industrial.html`: Industrial Revolution (steam, hydraulic, electric)
- `pages/modern.html`: Modern cranes (tower, mobile, crawler)
- `pages/milestones.html`: Technology milestones (timeline as text)
- `pages/future.html`: Cranes today and tomorrow

## Layout
- `css/tokens.css`: design tokens
- `css/layout.css`: page shell layout
- `css/site.css`: base styles
- `js/nav.js`: menu behaviour
- `js/app.js`: page behaviour
- `assets/`: reserved (the brief asks for no images)
